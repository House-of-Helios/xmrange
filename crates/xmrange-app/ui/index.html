XMRange connects only to the pool that you select. It uses Tor unless you turn Tor off. MoneroOcean sees your wallet address, worker name and hashrate. It sees your IP address only when Tor is off. On p2pool, peers see your IP address only when Tor is off. Your payout address is public on the p2pool share chain.

low power mode

✓ detected
  1. Open Battery settings (button above).
  2. Select Low Power Mode.
  3. Choose Always or Only on Power Adapter.

your monero node

p2pool needs a monero node on this mac. You can use the node of the Monero GUI (the steps below). Or XMRange can run its own node: in settings, set monero node to xmrange, then choose a chain folder. An external drive is fine. The first sync takes one day or more.

✓ ready
  1. Open the Monero GUI. In Settings → Node, choose Local node.
  2. In Daemon startup flags, add this flag: --zmq-pub tcp://127.0.0.1:18083
  3. Start the node. Let it sync. XMRange checks the node every 10 s.

      fetch the xmr price?

      Each hour, XMRange gets the XMR price in US dollars from Kraken. If Kraken fails, it uses Yahoo Finance. It always connects through Tor.

      Kraken and Yahoo see a Tor exit, not your IP address. They get no data about your wallet or mining. This adds one connection to the Tor network, also when you mine directly.
